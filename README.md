# ミニゲーム対戦(QR接続・サーバー不要)

GitHub Pages などの静的ホスティングだけで動く、スマホ同士の2人対戦ミニゲーム集です(オセロ / 四目並べ / 反射神経バトル / 甲虫じゃんけんバトル / ビッグスターバトル)。
WebRTC DataChannel で端末同士が直接通信し、接続情報はQRコード(またはコピー&ペースト)で交換します。

## 遊び方
1. 両者がこのページを開く(カメラ利用のため **HTTPS** で配信すること)
2. Aさん「対戦を作成」→ 招待QRを表示
3. Bさん「対戦に参加」→ 招待QRを読み取る → 返信QRが表示される
4. Aさん「② 相手の返信を読み取る」→ Bさんの返信QRを読み取る
5. 接続されるとゲーム選択画面になる(どちらが選んでも両方で開始。先手・色はAが先)

カメラが使えない場合は、表示されたコードをコピーしてLINE等で送り、貼り付けても接続できます。

## 公開方法
リポジトリのルートをそのまま GitHub Pages(Settings → Pages → Deploy from a branch)で公開してください。
ローカル確認: `npx serve .` や `python -m http.server`(localhost はカメラ可。LAN内IPはHTTPSが必要)。

## 構成
- `index.html` / `style.css` — 画面
- `js/othello.js` — オセロのルール(純粋ロジック)
- `js/mushi.js` — 甲虫じゃんけんバトルのルール(純粋ロジック・乱数なし)
- `js/vs/` — ビッグスターバトル(`sim.js` 決定論シミュレーション / `stages.js` / `render.js` / `input.js`)
- `tests/vs-sim.test.mjs` — `node tests/vs-sim.test.mjs` でシミュレーションを検証
- `js/games/` — 各ゲーム(`othello.js` `connect4.js` `reaction.js` `mushi.js` `vs.js`)と一覧 `index.js`
- `js/rtc.js` — WebRTC と接続コードの圧縮/展開
- `js/app.js` — UI・QR・対戦制御
- `vendor/` — qrcode-generator(MIT)、jsQR(Apache-2.0)

## 注意
- 接続コード交換後はGoogleのSTUNを補助的に使います。同じWi-Fiでもルーターの「AP分離」が有効だと繋がりません。
- 一部のネットワーク(厳しいNAT)ではTURNが無いと接続できない場合があります。
- iOS Safari は 16.4 以降を推奨(接続コードの圧縮に使用)。

## 甲虫じゃんけんバトルのルール
カードバトル系アーケードゲーム(甲虫王者ムシキング)のルールを、公開情報を元に再現しています(名称・カード・技名はすべてオリジナル)。

確認できた公開情報に基づく部分:
- ムシ1匹を選び、グー・チョキ・パーにわざカードを付ける。じゃんけんで勝った側だけが攻撃し、体力が0になった方の負け。
- あいこは、お互いに最大体力の1/10のダメージ(小数点以下切り捨て。10連続あいこで倒れる)。
- ムシの必殺わざの手で勝つと必殺わざ(ゲージなし)。同名の超必殺カードを付けていれば超必殺わざ。
- それ以外の手で勝つと通常攻撃。目押しゲージ(攻撃パーフェクト > 攻撃UP > 防御UP > 防御パーフェクト)でダメージが増減。
- つよさ100〜200、わざカードの攻撃ボーナス表、特殊わざ(かいふく等)の効果の割合。

**推定値・独自解釈**(非公開のため):
- 基礎体力・基礎攻撃力・各ダメージの倍率(`js/mushi.js` の `maxHpOf` / `baseAtk` / `K`)。
- 特殊わざは「その手で勝ったとき発動」と解釈。使える特殊わざは6種のみ。
- 実機にあるおたすけ昆虫、Vガジェ、ムシごとの性格(アタック/ディフェンス)、タッグ戦は未実装。
## ビッグスターバトル(横スクロール2Dアクション対戦)
「Newスーパーマリオブラザーズ」のマリオVSルイージ モードの遊び方を、公開されている解説を元に再現しています(キャラ・絵・音・ステージはすべてオリジナル)。

再現しているルール:
- 先に目標数(3/5/10)のビッグスターを集めた方がラウンド勝利。先取ラウンド数(1/2/3)で試合決着。ライフ(3/5/∞)が0になると負け。
- スターはステージ上の決まった場所のどこかに出現。取るとステージ(ブロック・コイン・敵)が元に戻り、約10秒後に次のスターが出る。
- 相手を**踏む**/**ファイアボール**/**コウラ**/**星・巨大化での体当たり**/**ブロックの下から突き上げ**/**穴に落とす**とスターを奪って落とせる。**ヒップドロップ**は一度に3つ。走って相手にぶつかると両者とも1つ落とす。落ちたスターは跳ね回り、拾われないと消える。
- ダメージを受けると、のけぞり(スタン)→約1秒の無敵。やられるとパイプからちいさい姿で復活(スター・コインは維持)。
- コインを8枚集めると上からランダムなアイテム(キノコ・ファイアフラワー・コウラ・ミニキノコ・スター・巨大キノコ)が降る。
- ステージはループする(こおりのだいちを除く)。壁キック、ステージ全体マップ、画面外スターの矢印あり。

未実装・簡略化: ストックアイテム、ワープパイプのステージ、クラッシャーのステージ、ドッスン等のギミック、タッチ操作以外の細かな調整(数値は推定)。

通信はロックステップ方式: 毎フレームの入力だけを交換し、両端末が同じシミュレーションを計算します(スターの取り合いなども両者で必ず一致)。120フレームごとにハッシュを比較し、ずれたら画面に警告を出します。
