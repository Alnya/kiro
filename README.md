# ミニゲーム対戦(QR接続・サーバー不要)

GitHub Pages などの静的ホスティングだけで動く、スマホ同士の2人対戦ミニゲーム集です(オセロ / 四目並べ / 反射神経バトル / 甲虫じゃんけんバトル / ビッグスターバトル / デッキタワー(協力) / 鬼面の武将 一騎討ち(3D))。
WebRTC DataChannel で端末同士が直接通信し、接続情報はQRコード(またはコピー&ペースト)で交換します。

## 遊び方
1. 両者がこのページを開く(カメラ利用のため **HTTPS** で配信すること)
2. Aさん「対戦を作成」→ 招待QRを表示
3. Bさん「対戦に参加」→ 招待QRを読み取る → 返信QRが表示される
4. Aさん「② 相手の返信を読み取る」→ Bさんの返信QRを読み取る
5. 接続されるとゲーム選択画面になる(どちらが選んでも両方で開始。先手・色はAが先)

カメラが使えない場合は、表示されたコードをコピーしてLINE等で送り、貼り付けても接続できます。

## 公開方法
リポジトリのルートをそのまま GitHub Pages(Settings → Pages → Deploy from a branch)で公開してください。
ローカル確認: `npx serve .` や `python -m http.server`(localhost はカメラ可。LAN内IPはHTTPSが必要)。

## 構成
- `index.html` / `style.css` — 画面
- `js/othello.js` — オセロのルール(純粋ロジック)
- `js/mushi.js` — 甲虫じゃんけんバトルのルール(純粋ロジック・乱数なし)
- `js/vs/` — ビッグスターバトル(`sim.js` 決定論シミュレーション / `stages.js` / `render.js` / `input.js`)
- `js/duel/` — 鬼面の武将 一騎討ち(`combat.js` ボス戦のロジック / `pvp.js` 対人戦のロジック / `pvpgame.js` 対人戦の描画・通信 / `rig.js` `models.js` `anim.js` キャラ / `world.js` 舞台 / `fx.js` エフェクト / `audio.js` 効果音 / `game.js` 描画・操作・HUD)
- `js/spire/` — デッキタワー(`data.js` カード・敵・レリック等のデータ / `engine.js` ゲームエンジン)
- `tests/` — `vs-sim` / `spire-rules` / `spire-cards` / `spire-bot` / `duel-combat` / `duel-pvp` の各 `.test.mjs`(`node tests/<名前>.test.mjs`)
- `js/games/` — 各ゲーム(`othello.js` `connect4.js` `reaction.js` `mushi.js` `vs.js` `spire.js` `duel.js`)と一覧 `index.js`
- `js/rtc.js` — WebRTC と接続コードの圧縮/展開
- `js/app.js` — UI・QR・対戦制御
- `vendor/` — qrcode-generator(MIT)、jsQR(Apache-2.0)、Three.js r160(MIT、`vendor/three/`。CDNは使わない)

## 注意
- 接続コード交換後はGoogleのSTUNを補助的に使います。同じWi-Fiでもルーターの「AP分離」が有効だと繋がりません。
- 一部のネットワーク(厳しいNAT)ではTURNが無いと接続できない場合があります。
- iOS Safari は 16.4 以降を推奨(接続コードの圧縮に使用)。

## ゲームを追加するには
js/games/<name>.js に `{ id, name, desc, create({root, role, send}) }` を default export し、js/games/index.js の配列に追加します。create は `{ onMessage(data), destroy() }` を返します。role は 0=作成側 / 1=参加側、send(data) で相手の onMessage にデータが届きます。

## 甲虫じゃんけんバトルのルール
カードバトル系アーケードゲーム(甲虫王者ムシキング)のルールを、公開情報を元に再現しています(名称・カード・技名はすべてオリジナル)。

確認できた公開情報に基づく部分:
- ムシ1匹を選び、グー・チョキ・パーにわざカードを付ける。じゃんけんで勝った側だけが攻撃し、体力が0になった方の負け。
- あいこは、お互いに最大体力の1/10のダメージ(小数点以下切り捨て。10連続あいこで倒れる)。
- ムシの必殺わざの手で勝つと必殺わざ(ゲージなし)。同名の超必殺カードを付けていれば超必殺わざ。
- それ以外の手で勝つと通常攻撃。目押しゲージ(攻撃パーフェクト > 攻撃UP > 防御UP > 防御パーフェクト)でダメージが増減。
- つよさ100〜200、わざカードの攻撃ボーナス表、特殊わざ(かいふく等)の効果の割合。

**推定値・独自解釈**(非公開のため):
- 基礎体力・基礎攻撃力・各ダメージの倍率(`js/mushi.js` の `maxHpOf` / `baseAtk` / `K`)。
- 特殊わざは「その手で勝ったとき発動」と解釈。使える特殊わざは6種のみ。
- 実機にあるおたすけ昆虫、Vガジェ、ムシごとの性格(アタック/ディフェンス)、タッグ戦は未実装。
## ビッグスターバトル(横スクロール2Dアクション対戦)
「Newスーパーマリオブラザーズ」のマリオVSルイージ モードの遊び方を、公開されている解説を元に再現しています(キャラ・絵・音・ステージはすべてオリジナル)。

再現しているルール:
- 先に目標数(3/5/10)のビッグスターを集めた方がラウンド勝利。先取ラウンド数(1/2/3)で試合決着。ライフ(3/5/∞)が0になると負け。
- スターはステージ上の決まった場所のどこかに出現。取るとステージ(ブロック・コイン・敵)が元に戻り、約10秒後に次のスターが出る。
- 相手を**踏む**/**ファイアボール**/**コウラ**/**星・巨大化での体当たり**/**ブロックの下から突き上げ**/**穴に落とす**とスターを奪って落とせる。**ヒップドロップ**は一度に3つ。走って相手にぶつかると両者とも1つ落とす。落ちたスターは跳ね回り、拾われないと消える。
- ダメージを受けると、のけぞり(スタン)→約1秒の無敵。やられるとパイプからちいさい姿で復活(スター・コインは維持)。
- コインを8枚集めると上からランダムなアイテム(キノコ・ファイアフラワー・コウラ・ミニキノコ・スター・巨大キノコ)が降る。
- ステージはループする(こおりのだいちを除く)。壁キック、ステージ全体マップ、画面外スターの矢印あり。

未実装・簡略化: ストックアイテム、ワープパイプのステージ、クラッシャーのステージ、ドッスン等のギミック、タッチ操作以外の細かな調整(数値は推定)。

通信はロックステップ方式: 毎フレームの入力だけを交換し、両端末が同じシミュレーションを計算します(スターの取り合いなども両者で必ず一致)。120フレームごとにハッシュを比較し、ずれたら画面に警告を出します。
## デッキタワー(協力デッキ構築ローグライク)
「Slay the Spire 2」の協力プレイの仕様(公開されている解説)を元にした、2人用の協力デッキ構築ローグライクです。カード・敵・絵・名前はすべてオリジナルです。

再現している協力ルール:
- 全員が**同時に**ターンを進め、カードの使用は到着順に1枚ずつ解決される。全員が「ターン終了」を押すと敵が行動(押した後も、全員が終わるまでは取り消せる)。
- デッキ・手札・エナジー・HP・ゴールド・レリック・ポーションは**個人**のもの。マップと敵は**共通**で、敵に付けた弱点・脱力などは全員に効く。
- 敵のHPは「基本値 × ACT補正(1.1) × 人数」。攻撃力は変わらない。攻撃は2人にばらけて向かう。
- マップの分かれ道は**投票**(割れたら抽選)。報酬・ショップの品揃えは各自別。
- 休憩所は全員が同時に選べる(休息 / 鍛冶 / **治療=味方を30%回復**)。宝箱は人数+1個のレリックから各自1つ選び、被ったら抽選で決着。
- HPが0になると、その戦闘中は戦闘不能。**戦闘後にHP1で復活**。
- 協力専用カード: 味方にブロックやエナジー・回復を渡す、敵の攻撃を自分に集める(挑発)、ブロックを共有する(守りの絆)など。ポーションは味方にも使える。

内容: クラス3種(ナイト/メイジ/レンジャー、各約17枚)、無色の協力カード3枚、敵13種(エリート2・ボス2)、レリック14個、ポーション6種、イベント5種、ランダム生成マップ(11階+ボス)。強化、ショップ(カード削除あり)、報酬、ポーションに対応。

通信: **ホストだけがゲームエンジンを実行**し、結果の状態を両者に配ります(ゲストは操作を送るだけ)。

簡略化・未実装: 現状はACT1のみ(ボスを倒すとクリア)。エンシェント、ボスレリック、カスタムモード、3〜4人プレイ、画面共有のカーソルは未実装。カード数・敵の種類はオリジナルゲームよりずっと少ない。難易度の数値は推定。

## 鬼面の武将 一騎討ち(3D剣戟アクション)
Three.js で描画する、ボスとの1対1の剣戟アクションです(SEKIROのような遊び方。キャラ・名前・絵・音はすべてオリジナルで、モデル・テクスチャ・効果音もコードで生成しています)。

ルール:
- 自分とボスにはそれぞれ **体力** と **体幹** がある。ボスの体幹を満タンにするか体力を0にすると隙ができ、**致命の一撃**を入れられる。ボスを倒すには致命の一撃が2回必要。2回目は後半戦になり、ボスの攻撃が激しくなる。
- 攻撃に合わせて **ジャストで防御** するとパリィ(弾き)になる。受付はボタンを押してから0.22秒。連打していると0.11秒に短くなる。パリィするとボスの体幹が大きく削れ、反撃のチャンスになる。普通の防御でも攻撃は防げるが、自分の体幹が溜まり、満タンになると崩される。
- 「危」マークが出る攻撃(突き・足払い・掴み)は防御もパリィもできない。回避でかわす。
- 回復(瓢箪)は3回まで。一度だけ、その場で回生(復活)できる。

操作:
- スマホ: 左側のスティックで移動。右側のボタンは 攻撃 / 防御(パリィ) / 回避 / 🍶回復。
- PC: WASDで移動。攻撃は J・Z・Enter・左クリック、防御は K・X・Shift・右クリック、回避は Space・L・C、回復は E・H、一時停止は Esc。

画質: 「高 / 標準 / 低」を選べる。低ではブルームと影を切る。初期値は端末に合わせて決まり、選んだ設定は端末に保存される。

モードは2つ:
- **ボス戦(ひとり)**: 2人はそれぞれ自分の端末で同じボスと戦う。相棒の進み具合(ボスの形態と残り体力、倒れたかどうか、討伐タイム、パリィ回数)を画面に表示する。勝敗は付けず、タイムを競う。
- **対人戦(2人)**: 二人とも「対人戦」を押すと始まる。剣士どうしの三本勝負で、先に二本取った方の勝ち(最大5本。引き分けの本は数えない)。
  - 体幹を崩して致命の一撃を入れるか、体力を0にすると一本。99秒の時間切れは残り体力の多い方が一本。
  - パリィされた側は体勢を崩して体幹が大きく溜まる。普通の防御は防いだ側の体幹が溜まる。
  - 対人戦専用の **突き(危)** は防御もパリィもできない。回避でかわし、相手に向かって踏み込みながら回避すると「見切り」で、突いた側の体幹が大きく崩れる。PCでは Q で突き。
  - 瓢箪は1本につき2回。戦績(勝・敗・分)は端末に保存される。

対人戦の通信: ビッグスターバトルと同じロックステップ方式。毎フレームの入力だけを交換し(入力遅延4フレーム)、両端末が同じ計算をする(`js/duel/pvp.js`)。端末ごとに結果がずれないよう、三角関数は自前の決定論的な実装を使い、乱数は使わない。入力遅延の分だけ、攻撃が当たった直後の防御もパリィとして扱う。120フレームごとにハッシュを比べ、ずれたら画面に警告を出す。

注意: 難易度はボットでの試行を元に調整しています。古いスマホでは「低」画質を推奨します。
